## FAQ

**Does it work for streaming on public Wi‑Fi?**  
Yes. AES-256 encryption protects traffic, and the Kill Switch helps prevent leaks if the connection drops.

**Will it slow down my video?**  
Any VPN adds overhead, but this is tuned for **high speed** and stable routing. Use the closest server for best results.

**What happens if the VPN disconnects mid-stream?**  
Enable the **Kill Switch**. It blocks traffic until the tunnel is back, so your real IP isn’t exposed.

**Is there logging?**  
The product states a **No-Logs policy** with a privacy and security focus.
